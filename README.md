# SNARE

3D-хоррор от первого лица на **Godot 4.3+ (GDScript)**. Всё сделано «из коробки»: геометрия,
материалы и звуки генерируются процедурно, внешние ассеты не нужны.

## Запуск

Откройте папку проекта в Godot 4.3+ (`Project → Import`) и нажмите F5. При первом открытии
Godot создаст `.godot/` с кэшем импорта — это нормально.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение |
| Shift | Бег (шумит, тратит выносливость) |
| Ctrl | Присесть (почти не шумит) |
| Мышь | Обзор; при поломке фонаря — активно трясти мышью влево-вправо/вверх-вниз |
| E | Взаимодействие: батарейка / шкаф |
| F | Включить / выключить фонарик |
| R | Обслуживание фонарика (пошаговая замена батарейки) |
| Колесо мыши вверх / вниз | Открутить крышку / закрутить обратно |
| ЛКМ или E в режиме обслуживания | Вытряхнуть старую батарейку, затем вставить новую |
| Tab или Esc | Экстренно выйти из режима обслуживания (фонарик останется разобранным) |
| Q / Space | Дыхание в шкафу: вдох / выдох в зелёной зоне кольца (3 успеха — монстр уходит) |
| Esc | Пауза |

## Что реализовано

- **Runtime-генерация:** чанки 4×4 клетки (клетка 4 м) подгружаются вокруг игрока по 2 за кадр,
 Recursive Backtracker с дополнительными проходами и соединениями с соседними чанками гарантируют
 связность. Новый seed при каждом рестарте.
- **Навигация монстра:** `AStar3D` по графу клеток; рёбра добавляются/удаляются при проломе
 стен — без перепекания навигационных мешей.
- **Фонарик:** нестабильный контакт (случайные сбои даже при полном заряде, чаще при низком
 заряде и рядом с монстром), починка встряхиванием мыши, расход заряда; свет тускнеет ниже 20 %,
 трёхэтапная разборка (крышка → батарейка → крышка) с анимацией и звуками.
- **Шкафы:** настоящие щели между планками дверцы, свет фонаря выдаёт игрока, ритм-механика
 дыхания (3 срыва — монстр срывает дверцу).
- **Монстр:** процедурная иерархия с анимацией походки, головы и челюсти, 3D-хрипение, шаги,
 рёв; FSM `PATROL / INVESTIGATE / CHASE / SEARCH / CHECK_LOCKER / KILL` с director AI.
- **Атмосфера:** тёмный туман, почти полная темнота, объёмный конус фонаря с пылью,
 пост-Shader (зерно, хроматическая аберрация, виньетка, красный оттенок при страхе).

## Структура

```
scenes/  — main, player, world, enemy, ui
scripts/ — core, maze, player, interactables, enemy, ui
shaders/ — horror_postprocess.gdshader
```

Все звуки синтезируются в `scripts/core/audio_synthesizer.gd` в `AudioStreamWAV` при первом
обращении; материалы и шумовые текстуры — в `scripts/core/proc_materials.gd`.
